# スクリーンショット撮影ガイド

このディレクトリにデモ用の画像を配置してください。README から参照されます。

## 必要なファイル

| ファイル名 | 用途 | 推奨サイズ |
|-----------|------|-----------|
| `upload.png` | トップページ（アップロード前） | 1280 × 800 px |
| `loading.png` | 解析中オーバーレイ表示 | 1280 × 800 px |
| `result.png` | 結果ページ（人物カード表示） | 1280 × 800 px |

## 撮影手順

### 1. 開発サーバーを起動

```bash
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

### 2. ブラウザ設定

- ウィンドウサイズ: **1280 × 800** に固定（DevTools → Device Toolbar → Custom で設定可）
- ズーム: **100%**
- ダークモード: お好みで（アプリのデフォルト表示で撮影）

### 3. サンプル写真の用意

本物の自撮り写真を使う必要はありません。以下のいずれかを使用してください。

- [Pexels — フリー人物写真](https://www.pexels.com/ja-jp/search/%E4%BA%BA%E7%89%A9/) ← 商用利用可
- [Unsplash — フリー人物写真](https://unsplash.com/s/photos/portrait) ← 商用利用可
- ご自身の写真（任意）

**重要:** 第三者が特定できる写真を公開リポジトリに commit しないでください。フリー素材を推奨します。

### 4. 各スクリーンショットの撮り方

#### `upload.png`
1. トップページを表示
2. 写真をアップロードしてプレビューが表示された状態でキャプチャ
3. 送信ボタンが見えている状態が望ましい

#### `loading.png`
1. 写真を送信後、解析中オーバーレイが表示された瞬間にキャプチャ
2. スピナー・「診断中...」などのテキストが見えればOK

#### `result.png`
1. 結果ページが表示されたらキャプチャ
2. 人物名・マッチ率・特徴ブレイクダウンが全て表示されている状態

## 配置後の確認

画像を配置したら、README でプレビューが正しく表示されるか確認してください。

```bash
# ローカルの Markdown プレビュー（VS Code の場合）
# Ctrl+Shift+V でプレビューが開く
```

GitHub 上でも `main` ブランチにマージ後、README のレンダリングを確認してください。
